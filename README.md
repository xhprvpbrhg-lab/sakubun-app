# おはなしのたね

小学校低学年（1〜2年生）向けの「作文の発想力」を助けるWebアプリです。
作文そのものの完成度ではなく、「止まった状態から自分で1つ発想を出す」ことを繰り返し練習することを目的にしています。

## 遊び方

1. トップ画面の「はじめる」で、その日の3問がスタートします。
2. 絵（絵から発想モード）またはことば（ことばから発想モード）を見て、思ったことを自由に入力します。
3. 何も思いつかなければ「💡 ヒント」で、少しずつ助けになる質問が出てきます（自由回答→自由回答→選択肢→自由回答…と段階的に）。
4. 何か答えられたら、「もうすこし かんがえる」「ぶんに してみよう」「きょうは これで おわる」から選べます。
5. 3問終わると「きょうは ここまで！」画面になり、その日は終了です。

保護者向けの記録画面は `おうちの方へ` リンクから開けます（簡単な計算で保護者ゲート付き）。

## ローカルでの動かし方

このアプリは静的ファイルのみで動きますが、ブラウザのセキュリティ制限（file://での読み込み制限）を避けるため、簡易サーバーで開くことをおすすめします。

```bash
python -m http.server 8123
```

上記を実行後、ブラウザで `http://localhost:8123` を開いてください。
（Node.jsがある場合は `npx serve` でも構いません）

## フォルダ構成

```
index.html          こども用画面（ホーム／もんだい／ぶん作り）
parent.html          保護者向け画面
css/style.css        こども用画面の共通スタイル
css/parent.css       保護者画面の追加スタイル
js/data.js           もんだいデータ（絵・ことば、各12問。JSON互換の構造）
js/storage.js        localStorage 読み書き（きろく・きょうの進行状況）
js/engine.js         ヒントの段階（ラダー）を組み立てるロジック
js/app.js            こども用画面のコントローラー
js/parent.js         保護者画面のコントローラー
```

## もんだいの追加方法

`js/data.js` の `SAKUBUN_DATA.picture` / `SAKUBUN_DATA.word` に項目を追加するだけで、自動的に出題プールに反映されます。

- 絵から発想: `{ id, difficulty(1 or 2), title, svg, feelingChoices?, reasonChoices?, afterChoices? }`
- ことばから発想: `{ id, difficulty(1 or 2), words: [...], personChoices?, placeChoices?, feelingChoices?, afterChoices? }`

choices系は省略するとデフォルトの選択肢が使われます。

## 記録される項目（保護者画面のもと）

各問題ごとに、日付・モード・もんだい名・自力で答えられたか・使ったヒントの段階・発想が出た質問の種類（観察/人物/場所/行動/気持ち/理由/想像/このあと/自分だったら）・最終的な回答・文章化したかを `localStorage` に保存します。
